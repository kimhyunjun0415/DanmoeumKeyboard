# 단모음 키보드 (iOS, 초기 개발판)

삼성식 단모음 배열을 기반으로 한 **Swift/UIKit 커스텀 키보드**의 소스 프로젝트입니다.

## 현재 구현
- 3줄 단모음 배열과 한국어 음절 조합
- 연타 쌍자음(ㄱㄱ→ㄲ 등), 연타 모음(ㅏㅏ→ㅑ 등), 일부 복모음/겹받침
- 한/영 전환, 삭제, 공백, 줄바꿈, 글로브(다음 키보드)
- 시스템 다크모드 색상, 네트워크·전체 접근 권한 불필요

## 미구현 / 검증 필요
- 실제 iPhone 18 Pro에서 빌드·서명·설치 테스트 **미실시**
- 삼성 키보드의 연속 입력 시간 간격, 복합 조합, 편집 커서 이동 및 자동교정과 100% 동일하지 않음
- 긴 글로브 누르기 키보드 목록, 숫자·특수문자 전용 페이지, 햅틱, 길게 눌러 입력, 동적 높이 조정
- 텍스트 커서가 조합 도중 이동하거나 호스트 앱에서 텍스트가 바뀌는 경우 조합 경계 예외 처리
- 숫자·특수문자 입력은 현재 제한적임

## 빌드 경로

1. 프로젝트 파일 생성을 위해 [XcodeGen](https://github.com/yonaskolb/XcodeGen)을 사용합니다.
2. macOS 환경에서 프로젝트 폴더에서 `xcodegen generate`로 `.xcodeproj`를 생성합니다.
3. Xcode에서 `DanmoeumKeyboard` 앱과 `DanmoeumExtension` 타깃의 Bundle ID를 본인 고유값으로 수정합니다.
4. signing 설정을 본인 Apple 팀/프로비저닝에 맞게 구성한 뒤 아카이브합니다.
5. 서명된 IPA의 설치는 Apple 정책, 해당 프로비저닝과 설치 방법에 따라 진행합니다.

### Mac이 없을 때
- 저장소의 `.github/workflows/build.yml`은 GitHub Actions macOS 러너에서 **서명 없는 시뮬레이터 컴파일 확인**을 수행하도록 설정되어 있습니다. 성공해도 아이폰 설치용 IPA는 생성되지 않습니다.

- Windows에서 이 프로젝트를 GitHub에 올린 뒤 **Mac 클라우드 CI**에서 XcodeGen과 Xcode를 이용해 빌드할 수 있습니다.
- **중요:** 무료 Apple ID는 유료 Developer Program과 다른 서명·프로비저닝 제한이 있습니다. 클라우드에서 `빌드 성공`했다고 무료 Apple ID로 Sideloadly 설치 가능한 IPA가 자동으로 나오는 것은 아닙니다.
- 특히 앱에 **키보드 확장 타깃**이 포함되므로 앱과 확장 둘 다 정확히 서명해야 합니다.
- Mac이나 유료 개발자 계정 없이 확실히 설치 가능한 완전 무료 경로는 이 프로젝트에서 아직 검증하지 못했습니다.

## 사용 방법
설치 후 iOS **설정 → 일반 → 키보드 → 키보드 → 새로운 키보드 추가**에서 `단모음`을 선택합니다. 비밀번호 입력창, 일부 보안 입력창에서는 시스템 키보드로 바뀔 수 있습니다.

## 주의
이 프로젝트는 **소스 개발판**으로, 컴파일 또는 단말 테스트를 마친 완성 앱이 아닙니다. 금융정보·비밀번호 등 민감한 입력은 시스템 키보드를 사용하세요.
